# Lia Home

Connecte votre Home Assistant à l'application **Lia Home**, pour piloter votre maison où que vous
soyez. La liaison est chiffrée de bout en bout.

L'application Lia Home installe cette intégration et la tient à jour : aucun réglage n'est
nécessaire.

## Mise à jour manuelle

Seulement si l'application Lia Home le demande :

- **Home Assistant 2026.11 ou plus récent** : Paramètres › Marketplace › Lia Home › Mettre à jour,
  puis redémarrez Home Assistant.
- **Avec HACS** : HACS › Lia Home › Télécharger, puis redémarrez Home Assistant.

Si Lia Home n'apparaît pas, ajoutez le dépôt `lia-home/lia-ha-integration` (catégorie
« Intégration »). Vos réglages sont conservés.
